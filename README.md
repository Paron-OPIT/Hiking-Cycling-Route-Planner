# Hiking & Cycling Route Planner

A full-stack web application developed as part of my Computer Science studies.

## Features

- User registration and authentication
- Interactive Leaflet map
- Create and manage hiking/cycling routes
- Add geographic waypoints
- Edit and delete waypoints
- Store routes in MongoDB
- Deploy frontend and backend using Vercel

## Technologies

JavaScript
Node.js
Express.js
MongoDB
Mongoose
Leaflet
Vercel
HTML
CSS
